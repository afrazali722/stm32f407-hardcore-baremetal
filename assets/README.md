# LinkedIn illustration source (NOT lab measurements)

`animated-concept.gif` and `architecture-concept.png` were generated as
visual explainers. They do not show an actual connected oscilloscope,
measured DWT execution time, real serial logging or hardware snapshots.

**The infographic's “6432 cycles at 168MHz = 4.02us” is mathematically wrong.**
Correct: 6432 / 168 = 38.29us. At 16MHz it is 402us.

Do not repost the illustrations as factual engineering test evidence.
The SVG in `docs/data-flow.svg` is the recommended project graphic.
